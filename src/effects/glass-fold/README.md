# GlassFold (vanilla port)

WebGL “folded glass panes” background from GradFlow’s `type: "fold"` shader.

- **Runtime:** `createGlassFold.js` — Vite + vanilla JS (no React)
- **Shaders:** `vertex.glsl`, `fragment.glsl` (extracted from `gradflow` MIT)
- **React reference only:** `Demo.tsx.reference.tsx`
- **Raw extract:** `_ref/`

Al-Anad palette defaults: forest / deep / lime (`#1F6B45`, `#08291D`, `#B5D95B`).
