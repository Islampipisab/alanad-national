# Al-Anad National — Animated Produce Slider

A standalone, responsive HTML/CSS/JavaScript product-category slider.

## Run
Open `index.html` in a browser, or serve this folder with your existing local development server.

## Integration
- Copy the section markup from `index.html` into the products page.
- Add `styles.css` to your stylesheet bundle.
- Include `script.js` after the section markup.
- The slider is vanilla JavaScript and has no framework dependency.
- Replace the Unsplash image URLs in `styles.css` with Al-Anad's approved product photography.
- Replace the `#contact` CTA destination with the actual products/contact route.

## Features
- 5 product categories
- Autoplay (5 seconds), pause/resume
- Previous/next controls and pagination
- Category tab navigation
- Touch swipe / pointer drag
- Arabic RTL / English LTR switch
- Responsive mobile layout
- Reduced-motion support
- Gentle pointer tilt on desktop

The contact anchor is a placeholder. Product category descriptions are proposed marketing copy and should be reviewed by Al-Anad before publication.
