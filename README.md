# Al-Anad National — cinematic website

Premium Arabic-first redesign for العناد الوطنية.

## Stack

- Vite + vanilla JS
- GSAP + ScrollTrigger
- Lenis smooth scroll
- Custom AR/EN i18n (RTL/LTR)

## Scripts

```bash
npm install
npm run dev
npm run build
```

Dev server defaults to http://localhost:5173/
